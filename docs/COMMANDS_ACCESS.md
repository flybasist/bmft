# Справочник команд BMFT

Все доступные команды бота, сгруппированные по модулям.

## 🧙 Интерактивные wizard'ы и inline-кнопки

Некоторые админские команды в **групповых чатах** имеют интерактивный режим (wizard) —
вызов без аргументов открывает пошаговый мастер с inline-кнопками. Описанный ниже
старый синтаксис всегда работает и имеет приоритет (вызов с аргументами → legacy).

- **Wizard'ы:** `/welcome`, `/setprofanity`, `/setvip` (с reply), `/setlimit`, `/addban`,
  `/addtask`, `/addreaction`. Не работают в личке и для анонимных админов.
- **Отмена:** кнопка «❌ Отменить» или любая команда (`/cancel`, `/help` и т.д.).
- **Таймаут:** 5 минут бездействия → wizard автоматически отменяется.
- **Подтверждения:** финальные сообщения wizard'а удаляются через 60 сек (чистота чата).
- **Inline-кнопки:** ▶ (запуск) и 🗑 (удаление) рядом с каждой записью в `/listtasks`;
  🗑 рядом с записями в `/listbans`, `/listreactions`
  (до 50 кнопок на сообщение; для `/listreactions` — только когда список помещается в
  одно сообщение).

## 🔹 Основные команды (Core)

| Команда | Доступ | Описание |
|---------|--------|----------|
| `/start` | Все | Приветствие и инициализация чата в БД |
| `/help` | Все | Список всех команд |

## 🚦 Limiter — Контроль лимитов контента

| Команда | Доступ | Описание |
|---------|--------|----------|
| `/limiter` | Все | Справка по модулю |
| `/mystats` | Все | Ваша статистика лимитов за сегодня |
| `/getlimit` | Все | Текущие лимиты чата/топика |
| `/setlimit <тип> <кол-во>` | Админ | Установить лимит на тип контента. 🧙 wizard — выбор типа из кнопок + пресеты/своё число |
| `/setvip` (reply) | Админ | Выдать VIP ответом на сообщение. 🧙 wizard — подтверждение + ввод причины |
| `/removevip` | Админ | Снять VIP (ответом на сообщение) |
| `/listvips` | Админ | Список VIP-пользователей |

**Типы контента:** `text`, `photo`, `video`, `sticker`, `animation`, `voice`, `video_note`, `audio`, `document`, `location`, `contact`, `banned_words`

**Особые значения:** `0` = без лимита, `-1` = полный запрет

**VIP**: Выдаётся только ответом на сообщение пользователя. Режим `@username` не поддерживается.

## 🎯 Reactions — Реакции, фильтры и модерация

Модуль объединяет три подсистемы: автоответы, фильтр запрещённых слов, фильтр мата.

### Автоответы на ключевые слова

| Команда | Доступ | Описание |
|---------|--------|----------|
| `/reactions` | Все | Справка по автоответам |
| `/addreaction <паттерн> <ответ>` | Админ | Добавить автоответ. 🧙 wizard — pattern → description → ответ (reply-медиа пропускает шаг 3). Расширенные опции (`user:`, cooldown, daily_limit, content_type, delete) — только через legacy |
| `/listreactions` | Админ | Список автоответов + inline-кнопки 🗑 |
| `/removereaction <id>` | Админ | Удалить автоответ |

### Фильтр запрещённых слов

| Команда | Доступ | Описание |
|---------|--------|----------|
| `/textfilter` | Все | Справка по фильтру слов |
| `/addban <слово>` | Админ | Добавить запрещённое слово. 🧙 wizard — pattern → выбор действия (delete/warn/delete_warn) |
| `/listbans` | Админ | Список запрещённых слов + inline-кнопки 🗑 |
| `/removeban <id>` | Админ | Удалить запрещённое слово |

### Фильтр ненормативной лексики

| Команда | Доступ | Описание |
|---------|--------|----------|
| `/profanity` | Все | Справка по фильтру мата |
| `/setprofanity <действие>` | Админ | Включить фильтр (delete/warn/delete_warn). 🧙 wizard — выбор действия кнопками |
| `/profanitystatus` | Админ | Текущие настройки фильтра мата |
| `/removeprofanity` | Админ | Отключить фильтр мата |

## ⚙️ Работа с топиками (Telegram Forums)

Все модули поддерживают топики:

- Команда **в топике** → настройки применяются только к этому топику
- Команда **в основном чате** → настройки применяются ко всему чату
- Если настройки топика не заданы → используется fallback на общие настройки чата

## ⚠️ Важно для владельцев чатов

Бот проверяет админские права через Telegram API (`getChatMember`).
Продвинутые администраторы (promoted) получают полный доступ
ко **всем** админским командам бота, независимо от гранулярных прав Telegram
(«удалять сообщения», «добавлять админов» и т.д.).

Перед назначением администратора убедитесь, что ему можно доверять
управление лимитами, VIP-статусами, фильтрами и планировщиком.
