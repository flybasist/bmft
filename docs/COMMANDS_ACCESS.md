# Справочник команд BMFT

Все доступные команды бота, сгруппированные по модулям.

## 📱 Inline-меню (v1.2)

Начиная с v1.2, основная навигация — через **inline-меню** («одно окно»).
Команды `/help`, `/statistics`, `/limiter`, `/reactions`, `/scheduler` открывают
единое меню с кнопками. Все действия выполняются через Edit одного сообщения.

- Команда пользователя удаляется из чата автоматически.
- Кнопки меню работают **только для владельца** (того, кто вызвал команду).
- Таймаут: 5 минут бездействия → меню удаляется.
- Кнопка «❌ Закрыть» — немедленное удаление.

### Доступные экраны меню

| Экран | Что показывает |
|-------|---------------|
| 📊 Статистика | Моя неделя, статистика чата, топ активных |
| 🚦 Лимитер | Мои лимиты, лимиты чата, VIP-список (с кнопками 🗑) |
| 🎯 Реакции | Список автоответов (🗑), список банов (🗑), статус мата |
| ⏰ Планировщик | Список задач (▶ запуск, 🗑 удаление) |

## 🧙 Интерактивные wizard'ы

Админские команды с аргументами имеют интерактивный режим (wizard) —
вызов без аргументов открывает пошаговый мастер с inline-кнопками.
Вызов с аргументами → legacy-синтаксис (всегда работает).

- **Wizard'ы:** `/welcome`, `/setprofanity`, `/setvip` (с reply), `/setlimit`, `/addban`,
  `/addtask`, `/addreaction`.
- **Отмена:** кнопка «❌ Отменить» или любая команда.
- **Таймаут:** 5 минут бездействия → wizard автоматически отменяется.

## 🚦 Limiter — Контроль лимитов контента

| Команда | Доступ | Описание |
|---------|--------|----------|
| `/limiter` | Все | Открывает меню лимитера |
| `/setlimit <тип> <кол-во>` | Админ | Установить лимит. 🧙 wizard |
| `/setvip` (reply) | Админ | Выдать VIP. 🧙 wizard |

Действия через меню: «Мои лимиты», «Лимиты чата», «VIP-список» (с кнопками удаления).

**Типы контента:** `text`, `photo`, `video`, `sticker`, `animation`, `voice`, `video_note`, `audio`, `document`, `location`, `contact`, `banned_words`

**Особые значения:** `0` = без лимита, `-1` = полный запрет

## ⚙️ Работа с топиками (Telegram Forums)

Все модули поддерживают топики:

- Команда **в топике** → настройки применяются только к этому топику
- Команда **в основном чате** → настройки применяются ко всему чату
- Если настройки топика не заданы → используется fallback на общие настройки чата

## ⚠️ Важно для владельцев чатов

Бот проверяет админские права через Telegram API (`getChatMember`).
Продвинутые администраторы (promoted) получают полный доступ
ко **всем** админским командам бота, независимо от гранулярных прав Telegram
(«удалять сообщения», «добавлять админов» и т.д.).

Перед назначением администратора убедитесь, что ему можно доверять
управление лимитами, VIP-статусами, фильтрами и планировщиком.
